# DeFlick Content Gaps

The current build avoids fake public claims. The following items are still needed before the site can become a final public case-study portfolio.

## Brand assets

- Original high-resolution DeFlick logo file with transparent or clean export variants.
- Favicon and app icon exports derived from the approved logo.
- Approved wordmark usage rules.

## Showreel and video

- Homepage showreel or approved hero poster.
- Project main films.
- Short muted teaser clips for work cards.
- Captions files for all public films.
- Mux credentials if adaptive streaming should be used.

## Project verification

For each project:

- Final title.
- Exact client name.
- Year.
- Category.
- DeFlick role.
- Short approved summary.
- Full approved description.
- Services delivered.
- Credits.
- Awards only if verified.
- Cover image.
- Mobile cover.
- Poster image.
- Gallery images.
- Behind-the-scenes images.
- External video URL or uploaded film.
